철판·파이프·H빔 중량 계산 방법

철판, 파이프, H빔과 환봉은 중량 계산에 필요한 단면 치수가 다릅니다. 제관 계산기에서 재질과 형상을 고른 뒤 총중량과 단위중량을 구분해 읽는 방법입니다.

입력 전에 확인할 치수 기준

철판·파이프·H빔 중량 계산 방법 입력 항목
입력확인할 내용
형상철판·파이프·링·H빔·앵글·환봉 중 사용할 부재를 선택합니다.
치수판은 가로·세로·두께, 파이프는 OD·두께·길이 등 해당 형상의 값을 입력합니다.
재질탄소강·스테인리스·알루미늄 중 계산에 사용할 재질을 선택합니다.
수량한 개 중량과 별도로 필요한 개수를 입력합니다.

앱에서 계산하고 수정하는 순서

  1. 중량 계산에서 부재 형상을 선택합니다.
  2. 규격 또는 실제 치수를 입력합니다.
  3. 재질과 수량을 설정합니다.
  4. 계산하기로 총 kg와 단위중량을 확인합니다.
  5. 재질·두께·길이·수량을 바꾸면 다시 계산합니다.

kg/m와 kg/m², 총 kg 구분하기

판은 면적당 kg/m², 파이프·형강·환봉 등은 길이당 kg/m, 링은 한 개 중량을 함께 확인합니다. 총중량에는 입력한 수량이 반영됩니다.

단위중량을 이미 전체 길이나 수량이 반영된 총중량으로 읽으면 발주량을 잘못 잡을 수 있습니다. 결과의 단위와 수량을 같이 확인합니다.

파이프는 두께와 실제 외경을 넣습니다

파이프 무게는 관 내부가 빈 단면으로 계산합니다. 같은 호칭경이라도 두께가 달라지면 단위중량이 달라지므로 외경과 스케줄·두께를 확인합니다.

중실 환봉을 파이프로 계산하거나 파이프를 중실 원기둥으로 계산하지 않도록 먼저 형상을 맞춥니다.

재질 밀도와 실제 중량의 차이

앱은 탄소강 7.85, 스테인리스 7.93, 알루미늄 2.70 g/cm³의 재질값으로 계산합니다. 실제 합금·규격 공차에 따른 중량은 자재 성적서와 실측값으로 확인합니다.

예를 들어 탄소강 판 1,000×1,000×10 mm 한 장은 이 계산 기준에서 78.5 kg입니다. 인양 장비나 지지 구조의 허용 하중은 중량 계산과 별도로 검토합니다.
