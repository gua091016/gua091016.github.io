경판 노즐 위치·절단 전개 계산 방법

경판 위에 노즐 위치를 표시할 때는 수평거리와 곡면을 따라 잰 호길이, 탄젠트라인 기준을 구분해야 합니다. 제관 계산기의 경판 노즐 화면에서 위치와 절단 전개를 확인하는 방법입니다.

입력 전에 확인할 치수 기준

경판 노즐 위치·절단 전개 계산 방법 입력 항목
입력확인할 내용
경판 형상·외경경판 종류와 외경 D를 선택하고 사용자 형상은 깊이·크라운·너클 조건을 입력합니다.
노즐 중심 수평거리경판 중심에서 노즐 중심까지의 수평거리입니다. 표면 호길이가 아닙니다.
노즐 외경규격 선택 또는 실제 외경 직접 입력을 사용합니다.
T.L~플랜지면 높이탄젠트라인에서 플랜지면까지의 높이입니다. 비우면 컷만 계산하는 조건을 확인합니다.

앱에서 계산하고 수정하는 순서

  1. 경판 노즐 도구를 열어 실제 경판 형상을 선택합니다.
  2. 경판 외경과 필요한 사용자 형상 치수를 입력합니다.
  3. 중심~노즐 수평거리와 노즐 규격을 입력합니다.
  4. 필요하면 T.L 기준 플랜지면 높이와 둘레 등분을 지정합니다.
  5. 계산하기에서 호길이와 마이터 표를 확인합니다. 입력을 수정하면 다시 계산합니다.

경판 호길이는 표면을 따라 잽니다

앱의 호길이는 줄자를 경판 표면에 붙여 재는 길이이며 직선으로 잰 수평거리와 다릅니다. 경판 곡면이 끝나는 T.L(탄젠트라인)과 그 이후의 직선부 S.F도 구분합니다.

호길이 결과에는 직선부가 포함되지 않는다는 화면 안내를 확인하고 현장 기준선을 맞춥니다.

이 노즐 마이터 계산의 방향 조건

현재 경판 노즐 화면의 마이터는 경판 외면과 노즐 외경을 기준으로, 노즐이 경판 축과 평행한 수직 노즐인 경우입니다. 임의로 기울어진 노즐의 결과로 사용하지 않습니다.

1번 0°는 정점 쪽입니다. 가장 긴 쪽 끝을 기준으로 각 등분선에서 컷만큼 잘라내는 방향을 표와 도해에서 확인합니다.

플랜지면 높이와 파이프 길이

높이를 플랜지면까지 입력했다면 실제 파이프 길이를 정할 때 플랜지 길이를 따로 검토해야 합니다. 입력 높이를 곧바로 직관 절단 길이라고 해석하지 않습니다.

경판 종류나 깊이를 바꾸면 위치 호길이와 접촉 곡선도 달라질 수 있습니다. 확정한 형상으로 결과를 다시 계산해 출력합니다.
