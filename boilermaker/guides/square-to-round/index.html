제관 계산기 · 작업별 사용법

사각→원형·호퍼 전개도 그리는 법

사각에서 원형으로 이어지는 각원과 사각 입구가 좁아지는 호퍼는 필요한 입력과 전개 방식이 다릅니다. 제관 계산기에서 정사각·직사각·편심 형상을 구분해 계산하는 방법입니다.

입력 전에 확인할 치수 기준

사각→원형·호퍼 전개도 그리는 법 입력 항목
입력확인할 내용
사각→원형사각 변 A·B, 원형 지름과 높이 H를 입력합니다. 정사각 모드에서는 A를 사용합니다.
편심 X·Y편심을 켰을 때 원 중심의 A·B 방향 이동량을 입력합니다.
호퍼위 A1·B1, 아래 A2·B2와 높이를 입력합니다.
호퍼 편심편심 호퍼는 X·Y와 각 면의 결과를 함께 확인합니다.

앱에서 계산하고 수정하는 순서

  1. 사각→원형, 직사각→원형 또는 편심 사각→원형 중 형상에 맞게 엽니다.
  2. 사각 치수, 원형 지름, 높이를 입력합니다.
  3. 편심 작업이면 편심을 켜고 X·Y를 입력합니다.
  4. 계산하기로 면별 모선·삼각분할 길이와 전개도를 확인합니다.
  5. 사각→사각 호퍼는 별도 호퍼 도구에서 위·아래 치수를 입력합니다. 수정 후 다시 계산합니다.

사각→원형 전개는 높이와 실장을 구분합니다

H는 수직 높이이고 판에 옮기는 모선·대각선은 각 지점을 잇는 실제 길이입니다. 수직 높이만으로 모든 전개 선을 같은 길이로 그리지 않습니다.

화면의 A·B·C·D 코너와 원형 등분 번호를 맞추고 해당 코너의 실장표를 읽습니다.

편심을 켜면 대칭 조건이 달라집니다

원 중심이 이동하면 서로 마주 보는 면도 길이가 달라질 수 있습니다. 중심형 결과를 편심형의 모든 면에 반복 적용하지 말고 평면도와 면별 번호를 확인합니다.

편심 X는 A 방향, 편심 Y는 B 방향입니다. 실제 도면의 축과 화면의 방향을 먼저 맞춘 다음 수치를 넣습니다.

호퍼는 위·아래 사각 치수를 사용합니다

호퍼 도구에는 위 가로·세로와 아래 가로·세로를 각각 넣습니다. 원형 지름이 있는 각원 도구와 구분하세요.

결과의 A면·B면 경사 높이, 모서리 실장과 판 접는 각도를 확인합니다. 편심 호퍼는 면별 결과가 달라지므로 해당 면의 전개도를 사용합니다.
