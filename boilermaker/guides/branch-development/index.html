가지관·Y분기 바지관 전개 방법

배관 가지관 전개와 Y분기 바지관 전개는 연결 형상과 길이 기준을 먼저 구분해야 합니다. 제관 계산기에서 정각·경사 가지관과 동경·이경 Y분기 작업을 선택하는 방법입니다.

가지관 외경주관 외경과 분기관 외경을 각각 입력하거나 배관 규격에서 고릅니다.

앱에서 계산하고 수정하는 순서

  1. 직각·경사 분기는 가지관, 두 갈래 바지관은 Y분기를 선택합니다.
  2. 실제 외경과 분기 각도, 등분 조건을 입력합니다.
  3. Y분기는 동경 또는 이경 모드를 먼저 맞춘 뒤 각 입력을 채웁니다.
  4. 계산하기로 둘레 각도·호거리·컷 또는 몸통·가지 전개표를 표시합니다.
  5. 관경·각도·길이를 바꾸면 다시 계산하고 같은 등분 번호로 마킹합니다.

호칭경과 실제 외경을 구분합니다

가지관 계산의 OD는 실제 외경입니다. 호칭경 숫자를 mm 외경 칸에 그대로 넣지 않습니다. 규격 선택을 이용할 때도 적용된 실제 외경과 규격 기준을 확인합니다.

둘레 호거리는 등분 위치를 관 표면을 따라 잡는 값입니다. 각 지점에서 따낼 양과 혼동하지 않도록 좌표표의 열 이름을 확인합니다.

동경 Y분기와 이경 Y분기

동경 Y분기는 몸통과 양쪽 가지의 관경이 같은 조건입니다. 몸통이 크고 두 가지가 작은 이경 형상은 이경 모드를 사용합니다.

이경 모드에는 몸통 외경 D, 가지 외경 d와 판 두께 등의 입력이 있습니다. 동경 계산에서 외경 하나만 바꿔 이경관 결과로 사용하지 않습니다.

새들·피시마우스와의 연결

직관에 맞춰 파이프 끝을 따내는 작업은 새들 또는 피시마우스라고도 부릅니다. 연결 각도와 기준 길이를 먼저 정리한 뒤 해당 도구를 선택합니다.

서포트 높이나 실치수 감기 템플릿 중심으로 작업하려면 더미 앱의 새들 컷 사용법도 참고할 수 있습니다.
