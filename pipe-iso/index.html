현장 계산 기능

출력물뿐 아니라 3D 오프셋 계산과 엘보 마이타 계산 화면까지 함께 보여주면 앱이 훨씬 전문적으로 보입니다.

ISO 3D 오프셋 계산

롤 각도, 오프셋, 직관 Run 값을 입력해 3D 배관 형상과 구간별 절단 CUT 결과를 확인합니다.

엘보 마이타 계산

엘보 절단 기준을 시각적으로 확인하고 배 쪽, 목 쪽 치수를 구분해 현장 절단 기준으로 활용합니다.

주요 기능

실제 출력물과 계산 화면을 통해 배관 ISO 스케치, 커팅 리스트, 3D 오프셋, 엘보 마이타 계산 기능을 한눈에 확인할 수 있습니다.

ISO 스케치

  • 배관 라인과 피팅 배치
  • 치수 라벨과 피팅 라벨 표시
  • 용접 포인트 시각화

커팅 리스트

  • P별 SIZE, CL, CUT 정리
  • CUT 최종수량 자동 집계
  • 파이프 총 CUT 길이 확인

전문 계산

  • ISO 3D 오프셋 계산
  • 엘보 마이타 절단 계산
  • PDF 저장 및 공유

사용 목적

본 앱은 현장 작업자가 간단한 배관 ISO 스케치를 작성하고, 피팅별 치수와 커팅 길이를 빠르게 확인할 수 있도록 제작되었습니다. 실제 제작 및 시공 전에는 현장 도면, 프로젝트 사양서, 적용 코드, 자재 카탈로그, 감독자 검토 내용을 함께 확인해야 합니다.
