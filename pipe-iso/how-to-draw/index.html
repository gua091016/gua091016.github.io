배관 ISO 그리는 법

배관 아이소 도면, 아이소메트릭 도면 또는 ISO 스케치라고 부르는 배관 그림을 앱에서 작성하는 방법입니다. 현장 배관 ISO 계산기로 배관 경로를 그리고, 실제 센터 치수(CL)와 피팅을 입력한 다음 절단 길이(CUT)를 확인하는 순서로 진행합니다.

1. 배관 규격과 단위를 확인합니다

상단의 배관 규격 선택란에서 사용할 사이즈를 고르고, 단위를 mm 또는 inch로 맞춥니다. 접합 방식은 도면 설정에서 확인합니다. 같은 배관 경로라도 규격, 피팅 종류와 접합 방식에 따라 절단 계산에 쓰는 값이 달라질 수 있습니다.

처음에는 직선 두 구간과 엘보 하나처럼 간단한 경로로 시작하면 선과 치수를 수정하는 방법을 익히기 쉽습니다.

2. 선 도구로 배관 ISO 경로를 그립니다

하단의 선 도구를 누르고 직선을 선택하면 ISO 방향에 맞춰 그릴 수 있습니다. 시작 위치에서 끝 위치로 드래그하거나, 시작점과 끝점을 차례로 눌러 선을 만듭니다. 기존 선에서 이어 그릴 때는 연결할 끝점에서 시작합니다.

ISO 방향에 맞추기 어려운 구간은 선 도구의 자유 그리기를 사용합니다. 화면에 그린 선의 모양과 실제 배관 치수는 별도로 관리되므로, 경로를 그린 다음 각 구간의 CL을 입력해야 합니다.

3. 치수 도구로 실제 센터 치수(CL)를 입력합니다

치수 도구를 선택한 뒤 치수를 입력할 배관 선을 누릅니다. 구간에 사용할 실제 CL을 입력하고 적용합니다. 값이 바뀌면 같은 선을 다시 선택해 수정합니다. 입력할 때 선택한 단위를 함께 확인하세요.

화면에서 선을 길게 그렸다고 실제 CL이 길어지는 것은 아닙니다. 이 앱의 스케치는 실측 축척 도면이 아니므로 화면 길이를 자로 재서 절단 길이로 사용하지 않습니다.

4. 연결점이나 선을 선택해 피팅을 편집합니다

피팅 도구를 누르고 배관의 연결점 또는 선을 선택합니다. 연결 위치에 맞는 엘보, 티, 레듀샤, 플랜지 등의 피팅을 선택하고 규격과 각도를 확인합니다. 피팅을 바꿀 때도 해당 위치를 다시 선택해 수정합니다.

그림의 꺾임만 보고 계산을 끝내지 말고, 적용된 피팅과 접합 방식이 실제 사용할 자재와 맞는지 확인합니다. 피팅 치수는 CL에서 CUT를 구할 때 영향을 줍니다.

5. 각도 표시를 넣고 화면을 이동합니다

각도 도구를 선택하고 표시할 선을 누르면 각도 설정 화면을 열 수 있습니다. 수평·수직 기준과 원하는 각도를 확인합니다. 화면을 옮기거나 확대해서 확인하려면 이동 도구로 전환합니다.

단순한 스케치 편집과 별도로 옵셋 수치를 계산하려는 경우에는 앱의 2D 옵셋 계산 기능을 이용할 수 있습니다. 2D 옵셋·엘보 마이타 기능 소개에서 확인하세요.

6. 절단 결과에서 CL과 CUT를 구분합니다

상단의 절단 결과를 열어 구간별 값과 수량을 확인합니다. CL 미입력 구간을 먼저 채우고, SIZE·CL·CUT와 피팅 구성을 함께 검토합니다.

SIZE해당 구간의 배관 규격
CL구간에 입력한 센터 기준 치수
CUT피팅 공제와 설정을 반영한 절단 길이

CL과 CUT를 같은 값으로 보고 작업하지 않도록 주의합니다. 실제 제작 전에는 도면, 자재 치수와 현장 조건을 대조합니다.

7. 도면을 보관하고 PDF·DXF로 내보냅니다

편집할 도면은 저장·불러오기 기능으로 관리하고, 공유나 출력이 필요하면 내보내기에서 PDF 또는 DXF를 선택합니다. PDF·DXF 출력물과 다시 편집할 작업 도면은 용도가 다르므로 필요한 형식으로 보관하세요.

무료 내보내기 횟수와 Pro 이용 범위는 앱 소개의 무료 이용·Pro 안내에서 확인할 수 있습니다.

배관 아이소 도면을 그릴 때 자주 묻는 질문

선만 그리면 절단 길이가 나오나요?

실제 CL 치수와 배관 규격, 피팅·접합 설정을 확인해야 합니다. 화면에 보이는 선 길이만으로 실제 절단 길이를 판단할 수 없습니다.

이미 그린 배관의 치수나 피팅을 바꿀 수 있나요?

치수 도구로 선을 선택해 CL을 수정하고, 피팅 도구로 연결점이나 선을 선택해 피팅을 변경할 수 있습니다. 변경 후에는 절단 결과를 다시 확인합니다.

이 페이지에서 바로 배관 도면을 그릴 수 있나요?

이 페이지는 사용법 안내입니다. 배관 ISO 스케치 작성과 편집은 Android용 현장 배관 ISO 계산기 앱에서 진행합니다.
