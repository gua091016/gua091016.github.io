H빔 더미 서포트 따내기 계산 방법

파이프 대신 H형강으로 배관을 받치는 빔 더미는 플랜지와 웹의 따내기 형상을 함께 확인해야 합니다. 더미 서포트 계산기의 빔 더미 직관·엘보 화면을 사용하는 방법입니다.

H빔 더미 서포트 따내기 계산 방법 입력 항목
입력확인할 내용
받칠 배관 형상직관용 또는 엘보용 빔 더미를 선택합니다.
H빔 규격목록에서 선택하거나 H·B·웹 두께 t1·플랜지 두께 t2를 직접 입력합니다.
웹 방향웹 나란히·웹 직각 중 실제 배치에 맞는 방향을 선택합니다.
센터높이·배관 조건높이 기준과 주관 구경을 맞추고 엘보용은 반경도 확인합니다.

앱에서 계산하고 수정하는 순서

  1. 빔 더미 (직관) 또는 빔 더미 (엘보) 작업을 엽니다.
  2. 배관 규격과 H빔 단면 치수를 설정합니다.
  3. PLAN 그림을 보며 웹 나란히·웹 직각을 선택합니다.
  4. 센터높이를 입력하고 계산 결과 보기를 누릅니다.
  5. 플랜지·웹의 결과와 전개도를 확인합니다. 방향을 바꿨다면 다시 확정합니다.

웹 방향을 바꾸면 결과도 달라집니다

PLAN은 H빔을 위에서 내려다본 방향을 보여 줍니다. 웹 나란히와 웹 직각은 사진만 바꾸는 선택이 아니라 단면 그림·계산 결과·전개도에 함께 적용되는 조건입니다.

먼저 실제 설치 방향과 PLAN을 일치시키고 그 방향의 결과를 계산합니다. 다른 방향에서 출력한 플랜지·웹 치수를 섞어 쓰지 않습니다.

직접 입력할 때 H·B·t1·t2를 구분합니다

H는 단면 높이, B는 폭, t1은 웹 두께, t2는 플랜지 두께입니다. 규격표와 다른 부재를 쓰면 직접 입력값을 확인합니다.

단면 치수에 잘못된 조합을 넣으면 정상적인 따내기 형상을 계산할 수 없습니다. 입력 오류가 보이면 결과를 임의로 해석하기 전에 부재 치수와 단위를 다시 확인하세요.

가공 치수와 구조 검토의 범위

이 화면은 배관 곡면에 맞는 H빔의 따내기 치수와 길이를 확인하는 도구입니다. 지지 하중·좌굴·용접부 강도 등 구조 검토를 대신하지 않습니다.

실제 제작에 사용할 방향과 부재를 확정한 뒤 출력물을 보관하고, 현장 도면의 높이 기준과 대조합니다.
