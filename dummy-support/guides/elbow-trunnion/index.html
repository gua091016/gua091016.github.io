엘보 더미·트러니언 길이 계산 방법

엘보 곡면에 붙는 더미 파이프는 직관에 붙는 더미와 접촉 형상이 다릅니다. 엘보 더미 또는 트러니언 서포트의 길이와 절단 전개선을 확인하는 앱 사용법입니다.

앱에서 계산하고 수정하는 순서

  1. 홈에서 엘보 더미 작업을 선택합니다.
  2. KS·ASME 기준과 엘보·더미 구경을 설정합니다.
  3. 엘보 반경, 센터높이, 위치 각도와 둘레 등분을 입력합니다.
  4. 계산 결과 보기로 길이와 절단 전개표를 확정합니다.
  5. 위치나 규격을 변경하면 값을 수정하고 다시 계산한 표로 마킹합니다.

엘보 위치 45도는 고정 조건이 아닙니다

현재 화면에는 엘보 위치 각도 입력이 있습니다. 기본 45°는 엘보 가운데를 뜻하며 다른 위치를 검토할 때는 실제 위치에 맞춰 바꿉니다.

예시 그림은 45° 기준이므로 그림의 겉모양만 보고 모든 작업이 같은 위치라고 해석하지 않습니다. 입력한 위치 각도를 결과·출력물과 함께 확인합니다.

반경과 실측값을 먼저 맞춥니다

엘보의 곡률 반경이 바뀌면 더미가 접촉하는 곡면도 달라집니다. 같은 구경이라는 이유만으로 롱엘보 결과를 숏엘보에 그대로 적용하지 않습니다.

Pro의 실측값 기능에서는 실제 외경·반경 조건을 입력할 수 있습니다. 두께 보정 조건을 사용하는 경우에도 사용한 접촉 기준을 확인하세요.

직관 더미 전개선을 대신 쓰지 않습니다

직관의 원통면과 엘보의 곡면은 형상이 다릅니다. 직관 더미와 엘보 더미를 구분해 작업을 열고, 전개표의 시작 위치와 기준선을 확인합니다.

출력한 템플릿은 100% 크기와 눈금을 확인한 뒤 사용합니다. 이 기능은 가공 형상과 마킹 치수 계산이며 서포트의 허용 하중을 판정하는 기능은 아닙니다.
