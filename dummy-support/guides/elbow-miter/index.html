엘보 마이터·마이타 절단 전개 방법

기성 엘보를 원하는 각도로 가공할 때는 시작 각도와 남길 목표 각도, 외측 배와 내측 목을 구분합니다. 더미 서포트 계산기에서 엘보 마이터 절단선을 확인하는 순서입니다.

엘보 마이터·마이타 절단 전개 방법 입력 항목
입력확인할 내용
시작 엘보홈에서 실제 사용할 90° 또는 45° 엘보 작업을 선택합니다.
목표 각도0°보다 크고 시작 엘보 각도보다 작은 값입니다.

단위mm 또는 inch로 결과를 확인합니다.

앱에서 계산하고 수정하는 순서

  1. 실제 자재의 시작 각도에 맞는 엘보 마이터 작업을 엽니다.
  2. 배관 구경과 반경 조건을 선택합니다.
  3. 남길 목표 각도를 입력합니다.
  4. 계산 결과 보기로 외측·내측 치수와 절단 전개선을 확인합니다.
  5. 규격이나 목표 각도를 수정하면 결과를 다시 확정하고 같은 기준으로 마킹합니다.

남길 각도와 제거 각도를 구분합니다

90° 엘보를 60°로 맞추려는 작업에서 목표 각도는 60°이고 제거 각도는 30°입니다. 두 값을 바꿔 입력하지 않도록 화면의 시작→목표 표시를 확인합니다.

앱은 목표가 시작 각도보다 작아야 하는 조건을 검사합니다. 시작 자재가 45°인데 90° 작업을 골랐다면 작업 종류부터 다시 맞춥니다.

배·목과 표면 전개선의 기준

외측과 내측은 곡률 반지름이 다르므로 같은 각도라도 표면 길이가 다릅니다. 외측 치수를 내측에 그대로 옮기거나 센터 반경 값과 혼동하지 않습니다.

앱은 24등분을 기준으로 절단 전개를 계산합니다. 결과표와 도해에 표시된 시작 위치·절단 방향을 함께 확인합니다.

새우등 엘보 제작과는 다른 작업입니다

이 기능은 이미 곡면을 가진 기성 엘보를 목표 각도로 가공합니다. 여러 직관 조각을 이어 새우등 엘보를 만드는 작업은 조각 수와 이음각을 따로 계산해야 합니다.
